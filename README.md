# ימי הולדת במשפחה

אתר קטן שמציג את ימי ההולדת העבריים של המשפחה, ושולח מייל תזכורת אוטומטי
פעם בשבוע לכל מי שברשימה, על כל מי שיום ההולדת שלו חל בעוד שבועיים עד
חודש וחצי.

## איך זה עובד

- `data/birthdays.json` - רשימת השמות והתאריכים העבריים (המקור היחיד לעדכון תאריכים).
- כל יום, GitHub בעצמו מחשב את התאריך הגרגוריאני הקרוב לכל יום הולדת, ומעלה
  את האתר ל-GitHub Pages.
- כל יום ראשון, GitHub שולח מייל תזכורת לכל מי שברשימת התפוצה, על כל מי
  שיום ההולדת שלו נופל בחלון של 14-45 יום מהיום.
- הסיסמה לכניסה לאתר היא **mishpacha-tzevet-2026**. זו הגנה קלה בלבד מפני
  מבקרים מקריים, לא הגנה אמיתית - כל מי שיש לו קישור וסיסמה יכול להיכנס.

## הגדרה חד-פעמית (ב-GitHub)

1. **הפעלת GitHub Pages**: ב-repo, Settings → Pages → Source → בחרו
   "GitHub Actions".
2. **הוספת סיסמאות (Secrets)**: Settings → Secrets and variables → Actions →
   New repository secret. יש להוסיף שלושה:
   - `GMAIL_USER` - כתובת ה-Gmail שממנה יישלחו המיילים.
   - `GMAIL_APP_PASSWORD` - "סיסמת אפליקציה" של Gmail (לא הסיסמה הרגילה!
     יש ליצור אותה בחשבון Google: Security → 2-Step Verification (חייב
     להיות מופעל) → App passwords → ליצור סיסמה חדשה ולהדביק אותה כאן).
   - `RECIPIENTS` - כל כתובות המייל שיקבלו תזכורת, מופרדות בפסיק, לדוגמה:
     `a@gmail.com,b@gmail.com,c@gmail.com`
3. ברגע שהכל מוגדר, לכו ל-Actions → "Send Birthday Reminders" → Run workflow,
   והשאירו את ה-"dry run" מסומן (זה ברירת המחדל) → Run. זה ירוץ בלי לשלוח
   מייל בפועל, רק יראה ביומן (Logs) את כל התאריכים המחושבים - כדאי לבדוק
   שהתאריכים נראים נכונים לפני שסומכים על השליחה האוטומטית.
4. כשבטוחים שהכל תקין, אפשר להמשיך ולסמוך על הריצה האוטומטית (כל יום ראשון),
   או להריץ ידנית בלי לסמן "dry run" כדי לשלוח מייל אמיתי עכשיו.

## איך לעדכן תאריכים

לערוך את הקובץ `data/birthdays.json` ולהוסיף/לשנות שורה בפורמט:

```json
{ "name": "שם מלא", "day": 15, "monthKey": "Adar", "hebrewLabel": "טו' אדר" }
```

`monthKey` אחד מ: Nisan, Iyyar, Sivan, Tamuz, Av, Elul, Tishrei, Cheshvan,
Kislev, Tevet, Shevat, Adar.

## איך לשנות את הסיסמה לאתר

יש לשלוח לי את הסיסמה החדשה ואחליף את הקוד בהתאם (הסיסמה מאוחסנת בקובץ
כ-hash ולא כטקסט גלוי, כדי שלא תהיה חשופה לכל מי שמסתכל בקוד).
